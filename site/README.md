# Brian Ebiyau — academic site

Built with [Astro](https://astro.build).

```sh
npm run dev      # local dev server at http://localhost:4321
npm run build    # production build to ./dist
npm run preview  # preview the build
```

## Editing

- **Links, publications, teaching, service:** `src/consts.ts`
- **About & research text:** `src/pages/index.astro`
- **Portrait:** replace `src/assets/portrait.jpg`
- **CV:** built from `../cv/cv.tex` (see the build note at the top); copy `Brian_Ebiyau_CV.pdf` into `public/`
- **Colors & fonts:** `src/styles/global.css`
